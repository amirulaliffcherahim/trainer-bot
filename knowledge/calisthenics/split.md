# The 3x/Week Split & Run Integration

## The fixed skeleton
- Mon: Upper (push + pull) — recovery day from Sat long run, light
- Tue: Run (easy/tempo) — legs fresh after Mon upper, fine
- Thu: Legs (squat + single-leg) — morning/early, BEFORE the Thu easy run if
  same day; keep the run easy
- Fri: Core — light, 48 h before Sat long run
- Wed/Sun: rest
- Sat: Long run — legs must be fresh; no leg strength on Fri

## Integration rules
- Never do hard legs the day before a quality run (Thu legs → Thu easy run is
  acceptable; Sat long run → Fri is core only, and it stays light).
- Run before strength when both fall on the same day (run first, then
  strength) — or split morning/evening.
- After a missed strength day: skip it, don't stack two sessions the next day.
- Strength volume stays flat during taper week (maintenance only), and
  completely off 3–4 days before race day.

## Why it matters
- The posterior chain (glutes, hamstrings, calves) absorbs impact; stronger
  legs = fewer knee/shin problems across 21 km.
- Core work directly stabilizes the pelvis under fatigue — the #1 posture
  failure in the last 5 km of a half.
